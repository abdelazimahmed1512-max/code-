# مجمع عيادات شفا - نظام حجز المواعيد الطبية وإدارة العيادات

نظام مصغر متكامل لإدارة العيادات وحجز المواعيد الطبية، مصمم بالكامل باللغة العربية (RTL) بدون أي اعتماد على الذكاء الاصطناعي (كود برمجي نقي ومنظم 100%).

---

## 🚀 طريقة تشغيل المشروع على فيجوال ستوديو كود (VS Code)

### المتطلبات الأساسية:
- تثبيت **[Node.js](https://nodejs.org/)** (الإصدار 18 أو أحدث).
- محرر **Visual Studio Code**.

### خطوات التشغيل:

1. **فتح المشروع في VS Code**:
   - افتح برنامج VS Code.
   - اختر من القائمة: `File` -> `Open Folder...`.
   - حدد مجلد المشروع وافتحه.

2. **فتح موجه الأوامر (Terminal)**:
   - اضغط على اختصار: `` Ctrl + ` `` أو من القائمة العلوية: `Terminal` -> `New Terminal`.

3. **تثبيت الحزم والمكتبات**:
   ```bash
   npm install
   ```

4. **تشغيل السيرفر المحلي**:
   ```bash
   npm run dev
   ```

5. **فتح التطبيق في المتصفح**:
   - افتح الرابط الذي سيظهر لك في الـ Terminal:
   - عادة يكون: `http://localhost:3000` أو `http://localhost:5173`.

---

## 🛠 أوامر المشروع المتاحة

- `npm run dev`: تشغيل بيئة التطوير المحلية السريعة.
- `npm run build`: بناء ملفات الإنتاج والتأكد من خلو المشروع من أي أخطاء برمجية (`Production Build`).
- `npm run lint`: فحص أنواع TypeScript والتأكد من صحة الكود البرمجي بنسبة 100%.

## ✨ ميزات النظام الرئيسية

1. **بوابة تسجيل الدخول الأولى**: تسجيل اسم المريض ورقم هاتفه وعنوانه ومحافظته، وإرسال رسالة تأكيد نصية على الهاتف برمز تحقق.
2. **20 تخصصاً طبياً شاملاً**: أمراض القلب، الباطنة، العظام، الأطفال، العيون، الجلدية، الأنف والأذن، الأسنان، المخ والأعصاب، النساء والتوليد، المسالك، الجراحة، الصدر، النفسية، الروماتيزم، العلاج الطبيعي، الغدد، الكلى، الأوعية الدموية، والأورام.
3. **حساب ذكي للمواعيد المتاحة**: فحص جداول عمل الأطباء تلقائياً ومنع التضارب أو الحجز المزدوج.
4. **تذاكر كشف طبية معتمدة**: تتضمن كود الحجز ورقم السجل الطبي ورسوم الكشف وتوقيت الموعد وقابلة للطباعة المباشرة.
5. **لوحة تحكم المسؤول**: إدارة المواعيد، تغيير الحالات (مؤكد، قيد الانتظار، مكتمل، ملغي)، وإحصائيات الحجوزات والإيرادات.
6. **حفظ دائم للبيانات**: حفظ تلقائي في `LocalStorage` للمتصفح دون الحاجة لسيرفر خارجي.
